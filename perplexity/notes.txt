when we are reqired to select the messages to store in our database then that is called DATA MODELLING.
in a more detailed way Data modeling is the process of creating a visual blueprint that defines how data is structured, stored, and related within an information system to ensure consistency and efficient retrieval.


user model: 
    {
        _id,
        username,
        email,
        password,
        verified (yes/no)-bydefault false,
        createdAt,
        updatedAt
    }

chat model: 
    {
        _id,
        user,
        title,
        createdAt,
        updatedAt
    }

message model: 
    {
        _id,
        chat reference,
        content,
        role-[user,ai],
    }
